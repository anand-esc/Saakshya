# State Police Crime-Intel Mesh • Command Portal

> Production-Grade Law Enforcement Intelligence & Algorithmic Governance Web Application

Built with **React 18**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **Lucide React**.

---

## 🌟 Key Features

- 🛡️ **Cryptographic SHA-256 Ledger Grounding:** Every entity link, LPR hit, and dispatch record is anchored to an immutable SHA-256 hash.
- ⚖️ **Algorithmic Bias & Parity Audit Engine:** Evaluates False Positive Rates (FPR) across 8 municipal districts with interactive **Auto-Dampening Toggle Switches** for dispatch weights.
- 🗺️ **Spatial Density Hotspot GIS Map:** Mapped with mandatory **Data-Sufficiency Scores** (e.g. `Sufficiency: 98.4%`) to prevent algorithmic bias on under-sampled sectors.
- 🕸️ **SHA-256 Evidence Network Graph:** Node-link visualizer linking Suspects, Vehicles (LPR), Locations, CAD Incidents, and Officers.
- 👮 **Human-in-the-Loop (HITL) Action Logs:** Badge-verified decision feeds requiring Officer Badge ID, Supervisor Clearance, Mandatory Reason Codes, and hash stamps.
- 📋 **High-Target Dossier Directory:** Classified intelligence packets with risk scores, LPR histories, and printable packet summaries.
- ☀️ **Dual Theme Support:** Seamless toggle between **Executive Light Mode** and **Dark Executive Slate Mode**.

## 🚀 Quick Start

### 1. Installation

```bash
git clone https://github.com/supriya-cybertech/spcip_ui.git
cd spcip_ui
npm install
```

### 2. Run Local Development Server

```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

### 3. Production Build

```bash
npm run build
```
